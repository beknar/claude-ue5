# Asset attribution

Every visual and sound asset of this project, and where it comes from; and every other Unreal Engine asset on the project owner's machine: packs in the project that nothing uses yet, Fab downloads not added to it, engine plugins, packs in other formats and the KitBash3D kits.

The repository holds none of these assets: only scripts, source code and small data files. Packs, sounds and characters stay on the project owner's machine and are used under their store licences. The pictures committed under `docs/images` are renders made by this project.

- **Store links:** packs from the Fab store link to their listing (`https://www.fab.com/listings/<id>`). The id and the folder a pack adds to `Content/` are taken from the Fab download's own manifest in the launcher's vault, or from the launcher's listings database (`VaultCache/FabLibrary/listings_v1.db`).
- **Sellers:** a seller is named where the local Fab data or the pack itself names one. Otherwise the listing is the reference.
- **Location on disk:** the full path of every copy on the project owner's machine: the project's folder, the Fab download in the launcher's vault, the Unity or FBX download, a project opened from it in the repository's root, the files a script converted or unpacked under `SourceArt/`. Paths under `I:\game assets` are the owner's asset library, read only.
- **Used:** a pack is used when a script, a level's data or a gallery's list names its folder (`/Game/<folder>/`).
